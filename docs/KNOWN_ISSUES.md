# 알려진 문제와 검증 범위

이 문서는 2026-10-28 조사 시 확인한 한계입니다. 당시 김건우가 이를 발견·수정했다는 경험으로 귀속하지 않습니다.

## 미세먼지

- 네 입력 CSV가 없어 전체 재실행·병합 손실·연속 시간·평가 표본을 확인하지 못했습니다.
- 타깃 shift(-1)과 지연 shift(24)는 행 이동입니다. 누락/중복 시간 여부를 검증해야 실제 1시간·24시간 간격을 보장합니다.
- ffill/bfill과 현재 시점 입력의 가용성은 실제 서비스 예측 시점 기준으로 다시 검토해야 합니다.
- 발표의 딥러닝 표제와 실제 RF 내용이 일치하지 않는 부분이 있어 성과를 확대하지 않았습니다.

## HAR 기본 모델링

- 당시 저장 입력 크기638/798과 확보 CSV5881/1471의 불일치 원인은 미확인입니다. 정리본에서는 혼동을 피하려고 과거 출력을 제거했습니다.
- 일부 라벨 매핑에서 학습과 테스트의 계단 상/하향 인코딩이 일치하지 않습니다.
- 스케일러 비교 루프가 동일 MinMax 입력으로 학습하고 평가 입력만 바꾸는 구간이 있어 통제된 Standard/MinMax 비교가 아닙니다.
- 모델별 최종 테스트 비교에는 저장 결과가 없어 결과 우열을 확정하지 않습니다.

## HAR 단계별 모델

- 정적/동적 분류 후 각 세부 모델을 재학습하는 함수가 있으며 단순 추론 전용 API가 아닙니다.
- 이진 단계 출력이 6개인 설정, 빈 분기 처리 부재, 1차 예측의 예상 밖 클래스 처리, 라벨 복원 등을 재설계할 여지가 있습니다.
- 개별 실험과 통합 함수의 optimizer/ES 설정이 달라 개별 점수를 곱해 통합 성능으로 설명할 수 없습니다.
- 함수는 Activity가 포함된 테스트를 전제합니다. 라벨 없는 운영 입력용 배포 구현은 아닙니다.

## 현재 검증

- 4개 정리 노트북의 JSON 구조 및 일반 Python 셀 문법 확인.
- RF EDA의 전처리·8:2 분할·학습/평가만 현재 재실행. sklearn1.8.0 정확도0.979609.
- 당시 EDA 저장 결과 약0.980459와 조금 다릅니다. 환경 차이가 원인일 가능성은 있으나 원인을 버전 하나로 확정하지 않습니다.
- TensorFlow 미설치로 DNN 전체 미실행. requirements는 현재 실행 준비용이며 당시 환경 잠금 파일이 아닙니다.
