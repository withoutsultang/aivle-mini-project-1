# KT AIVLE 미니프로젝트 1차

공공데이터를 활용한 **1시간 후 미세먼지(PM10) 농도 예측**과 스마트폰 센서 기반 **6종 행동 인식(HAR)**을 수행한 7인 팀 프로젝트입니다.

- 과제1: 미세먼지 예측 — 2025-10-15
- 과제2: HAR 행동 분류 — 2025-10-16~17
- 이 저장소 정리: 2026-10-28. 당시 커밋 이력을 재현한 저장소는 아닙니다.

## 내 역할 — 김건우

코드 정리 서기와 두 과제의 조별 통합본 담당을 맡았습니다. 미세먼지 발표에는 김건우의 **PM10 제외 분석에서 시정 중요도 1위·CO 2위** 결과와 도메인 해석이 기록돼 있습니다. 개인 분석의 모델 종류·성능 수치는 확인되지 않았습니다.

아래 모델·파이프라인은 **팀 산출물**입니다. 모든 코드를 개인이 독립 작성했거나 계층 분류 설계를 처음 고안했다고 주장하지 않습니다. [역할·원본 근거](docs/PROVENANCE.md)

## 과제1 — 미세먼지 예측

서울 대기오염·기상 데이터를 시간 기준으로 결합하고 결측 처리, 날짜 특성, 24행 지연 특성, 다음 행 타깃을 구성했습니다. 공식 교안은 `PM10_1`을 **1시간 후 농도**로 정의합니다. 공통 전처리와 LR/RF/GradientBoosting/XGBoost 비교·튜닝 코드가 있습니다.

|팀 노트북의 저장 결과|MSE|R²|
|---|---:|---:|
|LinearRegression|51.56159|0.93193|
|RandomForest 기본|63.36674|0.91634|
|RandomForest 튜닝|55.43522|0.92681|
|GradientBoosting 기본|49.09368|0.93518|
|GradientBoosting 튜닝|48.32206|약 0.9362|
|XGBoost 기본|49.86905|약 0.93416|

위 수치는 **당시 저장 출력**이며 현재 재학습 결과가 아닙니다. 입력 원본 CSV가 없어 재실행하지 못했습니다. 본인의 PM10 제외 분석과 팀 통합본의 PM10 포함 모델 성능은 서로 다른 조건입니다.

## 과제2 — HAR

561개 센서 특성에서 RandomForest 중요도와 중력가속도 특성을 살펴보고, 기본 DNN과 정적/동적 분기 후 세부 행동을 분류하는 단계별 모델을 구성했습니다. 계층 구조 방향은 과제에서 제공됐으며 팀이 함수를 작성했습니다.

행동: `LAYING`, `SITTING`, `STANDING`, `WALKING`, `WALKING_UPSTAIRS`, `WALKING_DOWNSTAIRS`.

최종 단계별 노트북의 **저장 테스트 출력**은 1,471건 중 1,414건 정답, 57건 오분류(accuracy 약 0.96)입니다. SITTING→STANDING 37건, 반대 9건으로 두 정적 자세의 혼동이 남았습니다. ‘단일 모델 0.35→계층 모델 0.95’라는 동일 조건 개선 실험은 입증되지 않아 사용하지 않습니다.

별도 EDA RF 검증 스크립트는 2026-10-28 원본 학습 CSV로 재실행해 검증 정확도 0.979609를 얻었습니다. 이는 다른 실험이며 당시 계층 DNN의 성능을 재현한 결과가 아닙니다. [현재 검증 결과](results/har_eda_rerun.json)

## 파일 구성

- `notebooks/dust/`: 미세먼지 팀 노트북의 로컬 실행용 사본
- `notebooks/har/`: EDA·기본 모델링·단계별 모델링 사본
- `scripts/verify_har_eda.py`: 현재 작성한 RF EDA 제한 재현 스크립트
- `docs/`: 원본/변경 내역·알려진 문제·데이터 배치 안내
- `results/`: 현재 RF 재실행 결과

노트북은 개인 Google Drive 경로·마운트·자동 시스템 설치를 정리하고 실행 출력/실행 번호를 제거했습니다. **당시 모델링 로직과 알려진 오류는 보존**했습니다. 수정 내역은 [대장](docs/NOTEBOOK_PROVENANCE.json)에 기록합니다.

## 실행

Python 가상환경에서 기본 의존성을 설치하고 저장소 루트에서 Jupyter를 실행합니다.

```bash
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install -r requirements-dl.txt  # DNN 노트북 실행 시
jupyter lab
```

CSV는 포함하지 않습니다. [데이터 안내](docs/DATA.md)에 따라 배치한 뒤 각 노트북을 순서대로 실행하세요. 기본 모델링과 단계별 모델링은 각각 CSV를 직접 읽으며 EDA가 저장한 pkl을 연결하는 완성 파이프라인은 아닙니다. DNN의 전체 실행은 검증하지 않았습니다.

RF 제한 재현:

```bash
python scripts/verify_har_eda.py --data-dir data/har --output results/har_eda_current.json
```
