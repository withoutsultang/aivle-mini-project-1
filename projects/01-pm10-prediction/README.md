# 01 · 공공데이터를 활용한 미세먼지 농도 예측

**대기오염·기상 데이터를 결합해 1시간 후 PM10 농도를 예측한 회귀 모델링 프로젝트**

| 항목 | 내용 |
| --- | --- |
| 기간 | 2025.10.15 |
| 팀 | 7인 · KT AIVLE School 미니프로젝트 1차 과제1 |
| 개인 역할 | 김건우 · 코드 정리 및 조별 통합본 담당, PM10 제외 변수 중요도 분석 |
| 기술 | Python, Pandas, NumPy, scikit-learn, XGBoost, Matplotlib, Seaborn |
| 팀 성과 | **Gradient Boosting R² 0.9362 · MSE 48.3221** |

## 프로젝트 목표

대기오염 관측값과 기상 정보를 같은 시간축으로 결합하고, 관측·시간 특성을 활용해 **1시간 후 미세먼지 농도**를 예측했습니다. 데이터 구조를 이해하고 전처리한 뒤 여러 회귀 모델을 비교하고 하이퍼파라미터를 조정했습니다.

## 내가 담당한 일

- **코드 정리·산출물 관리:** 팀원들의 분석·모델링 작업을 정리하는 역할과 조별 통합본 관리를 담당했습니다.
- **변수 중요도 분석:** PM10을 제외한 조건에서 다른 변수의 중요도를 분석했습니다.
- **분석 결과 해석·공유:** 중요도 **1위 시정, 2위 CO**를 확인하고, 시정은 대기 중 부유물질과, CO는 차량·난방 등 연소활동과 연결해 팀 발표에 공유했습니다.

## 데이터 및 전처리 · 팀 구현

**에어코리아의 서울 종로구 대기오염 자료**와 **기상청의 서울 기상자료**를 사용했습니다. 2024년 데이터를 학습에, 2025년 데이터를 테스트에 활용했습니다.

1. **시간 정규화:** 대기자료의 24시를 다음 날 00시로 변환해 기상자료와 시간 기준을 맞췄습니다.
2. **데이터 결합·결측 처리:** 시간 키로 자료를 결합하고 강수량 0 대체와 `ffill`/`bfill`을 적용했습니다.
3. **특성 생성:** 월·일·시간, PM10의 24행 지연 특성, 다음 행의 PM10 타깃을 구성했습니다.
4. **모델링·튜닝:** Linear Regression을 기준으로 Random Forest, Gradient Boosting, XGBoost를 비교하고 교차검증 기반으로 하이퍼파라미터를 탐색했습니다.

## 모델 평가

| 모델 | MSE | R² |
| --- | ---: | ---: |
| Linear Regression | 51.5616 | 0.9319 |
| Random Forest | 63.3667 | 0.9163 |
| Random Forest · 튜닝 | 55.4352 | 0.9268 |
| Gradient Boosting | 49.0937 | 0.9352 |
| **Gradient Boosting · 튜닝** | **48.3221** | **0.9362** |
| XGBoost | 49.8691 | 0.9342 |

Gradient Boosting 튜닝 모델은 기본 모델 대비 **MSE를 약 1.57% 낮췄습니다.** Random Forest 역시 튜닝을 통해 MSE가 63.3667에서 55.4352로 감소했습니다.

*평가 표는 당시 팀 노트북의 저장 결과입니다. 개인의 PM10 제외 분석과는 입력 조건이 다릅니다.*

## 이 프로젝트에서 보여주는 역량

- **데이터 연결:** 서로 다른 시간 표현을 가진 공공데이터를 공통 기준으로 정리하는 전처리 과정
- **분석 결과 설명:** 변수 중요도를 나열하는 데서 나아가 도메인과 연결해 설명한 개인 분석
- **협업·산출물 관리:** 여러 팀원의 작업을 조별 결과물로 정리하는 역할
