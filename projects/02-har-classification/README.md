## 프로젝트 목표

스마트폰의 가속도·자이로 센서에서 추출한 특성을 분석하고, 사용자의 행동을 **걷기·계단 오르기·계단 내려가기·앉기·서기·눕기**로 분류했습니다.

탐색적 분석과 기본 DNN 실험을 거쳐, 정적·동적 행동을 먼저 나눈 뒤 세부 행동을 예측하는 단계별 분류 모델을 구성했습니다.

## 내가 담당한 일

**코드 정리 역할과 조별 통합본 관리**를 담당했습니다. EDA·기본 모델링·단계별 모델링으로 나뉜 팀의 작업을 조별 산출물로 정리했습니다.

아래 분석·모델 구조·성능은 팀 전체의 결과입니다.

## 구현 과정 · 팀 구현

### 1. 센서 특성 탐색

Random Forest 기반 변수 중요도를 분석하고 중력가속도 관련 특성을 살펴봤습니다. 시각화를 통해 행동별 특성 분포를 비교했습니다.

### 2. 기본 DNN 모델링

입력 스케일링과 DNN의 층 구성·학습 설정을 바꿔가며 행동 분류 모델을 실험했습니다.

### 3. 단계별 분류

과제에서 제시한 정적·동적 분류 방향에 따라, **1차 분류 → 분기별 세부 분류 → 라벨 결합**을 수행하는 함수를 구현했습니다.

| 단계 | 분류 내용 |
| --- | --- |
| **1차 모델** | 정적 행동 / 동적 행동 |
| **정적 행동 모델** | 앉기 / 서기 / 눕기 |
| **동적 행동 모델** | 걷기 / 계단 오르기 / 계단 내려가기 |
| **결과 결합** | 각 분기의 예측을 원래 6종 행동 라벨로 변환 |

분기별 전처리와 모델 학습, 예측 결과의 라벨 복원을 함수로 연결했습니다.
